# 🌐 Next Fiber - ISP Billing & Management Panel

A Web-based ISP Customer Management and Billing Dashboard built with Python (Flask), HTML5, Bootstrap 5, and MySQL.

## ✨ Features
- 📊 **Live Dashboard:** Total revenue, active customers, and expiry metrics.
- ➕ **Customer Management:** Add new users with IP/Account ID, package details, and expiration dates.
- 🏘️ **Town & Area Filtering:** Filter customer records by specific town or coverage region.
- 🗄️ **Database Persistence:** MySQL integration for safe, permanent record keeping.

## 🛠️ Tech Stack
- **Backend:** Python (Flask)
- **Frontend:** HTML5, CSS3, Bootstrap 5
- **Database:** MySQL
